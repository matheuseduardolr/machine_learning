# Projetos de Machine Learning

Repositório contendo projetos práticos de Machine Learning, abrangendo desde pré-processamento de dados até treinamento e avaliação de modelos.



## Projetos

### project_preprocessing_feature_engineering
- Pipeline de pré-processamento e feature engineering para dados de clientes, incluindo análise exploratória (EDA), tratamento de dados, transformação e criação de features.
- Estruturação do processamento com `Pipeline` e `ColumnTransformer` para imputação, encoding e normalização.
- **Tecnologias:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
